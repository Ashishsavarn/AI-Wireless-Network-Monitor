# AI Wireless Network Monitor

## Overview

AI Wireless Network Monitor is a real-time cyber-security monitoring system that captures, analyzes, and visualizes network traffic data. The system leverages machine learning–based anomaly detection to identify suspicious IP activity and potential network threats.

## Features

* Real-time network packet monitoring
* Protocol analysis (TCP, UDP, ICMP)
* AI-based anomaly detection
* Threat alert system
* Source and destination IP analytics
* Live network traffic visualization
* Protocol distribution dashboard
* Recent packet monitoring
* Auto-refresh monitoring dashboard

## Tech Stack

### Frontend

* React.js
* Recharts
* HTML/CSS

### Backend

* FastAPI
* Python

### Database

* SQLite

### Machine Learning

* Scikit-Learn
* Anomaly Detection

## System Architecture

Packet Capture → FastAPI Backend → SQLite Database → AI Anomaly Detection → React Dashboard

## Dashboard Modules

* Protocol Distribution Analysis
* Top Source IP Monitoring
* Top Destination IP Monitoring
* AI Threat Detection
* Live Traffic Analytics
* Recent Packet Tracking

## Future Enhancements
